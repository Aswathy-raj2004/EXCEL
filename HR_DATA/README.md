HR Analytics Dashboard : Developed an interactive HR Analytics Dashboard in Microsoft Excel to analyze workforce data, employee demographics, salary distribution, and organizational performance. The dashboard provides HR managers with key insights through dynamic visualizations, KPI cards, and interactive slicers for efficient workforce analysis.
Key Features :
KPI Cards displaying : Total Employees, Male Employees, Female Employees, Average Salary, Average Attendance, Average Performance Rating, Active Employees, Resigned Employees
Department-wise Employee Distribution
Department-wise Average Salary Analysis
Gender Distribution
Branch-wise Employee Count
Top 10 Employees by Salary
Employment Type Distribution
Slicers for Department, Branch, Emplyoment type, Gender
