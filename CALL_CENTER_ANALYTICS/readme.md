📞 Call Center Analytics Dashboard

An interactive Call Center Analytics Dashboard built using Microsoft Excel to analyze call volume, call channels, call status, customer satisfaction, and issue categories.

📊 Key Features

* Total Calls & other KPI metrics
* Calls by Channel
* Call Status Analysis
* Customer Satisfaction by Issue
* Issue-wise Call Analysis
* Interactive Slicers & Filters
* Pivot Tables & Pivot Charts

🛠️ Tools Used

* Microsoft Excel
* Power Query
* Pivot Tables
* Pivot Charts
* Excel Slicers
* Data Visualization

🎯 Objective

To transform raw call-center data into an interactive dashboard that provides meaningful insights into customer service performance and call-center operations.

📌 Skills Demonstrated

Data Cleaning | Data Analysis | Excel | Power Query | Dashboard Design | Data Visualization
